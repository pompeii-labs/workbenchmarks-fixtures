# Dolphin Coast

A small cozy Three.js game: swim a dolphin along a golden-hour coast, leap off the swell and land flips and spins for multiplied points.

- `npm install` then `npm run dev` to play locally.
- `npm run build` writes a static site to `dist/` (relative paths, so you can upload it to any folder).
- `npm run build:test` is the test build with automation hooks; never deploy it.

Controls: Down/S dive, Up/W rise and leap, Left/Right steer. In the air, Up/Down flip and Left/Right spin. Space sprints, P pauses. Touch: drag pad plus Kick button.
